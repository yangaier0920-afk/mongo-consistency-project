# Recorded source and naming migration

recorded_source/ preserves the exact Python files used for all three published batches. Historical source hashes, raw records, timestamps and audit artifacts were not rewritten. Original source names remain here for traceability only.

The public package is experiments/. Its only Python changes are byte substitutions `experiments_v2` -> `experiments` and `test_v2` -> `test_consistency`, plus renaming test_v2.py to test_consistency.py. These adjust module entry points and mock targets, not workload logic. scripts/verify_migration.py checks the exact transformation and all batch source hashes.

Use scripts/audit_published.py to audit historical batches against recorded_source. Use `python -m experiments.audit <new-batch>` for future runs made by the renamed package. Historical results must not be represented as generated by the renamed source bytes.
